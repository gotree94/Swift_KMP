> 배열, 딕셔너리, 집합, 튜플 등 여러 값을 다루는 컬렉션 자료구조를 학습한다.

## 학습 목표

- 딕셔너리(Dictionary)의 키-값 구조를 이해한다.
- 튜플과 옵셔널 자료형을 사용할 수 있다.

## 1. 배열 (Array)

동일한 타입의 값들을 순서대로 저장합니다.

```swift
// 1) 빈 배열 생성
var fruits: [String] = []
var numbers: [Int] = []

// 2) 리터럴 생성
var colors = ["red", "green", "blue"]

// 3) 요소 추가/변경/삭제
colors.append("purple")          // 맨 끝에 추가
colors.insert("black", at: 0)    // 0번 위치에 삽입
colors[1] = "orange"             // 1번 요소 변경
colors.remove(at: 0)             // 0번 요소 제거
fruits.removeAll()               // 전체 제거

print(colors)                    // ["orange", "green", "blue", "purple"]
print(colors.count)              // 4
print(colors.isEmpty)            // false
```

### 인덱스 순회와 관련 메서드

```swift
let scores = [95, 80, 70, 60]

for score in scores {          // 값 순회
    print(score)
}

for (index, score) in scores.enumerated() {   // 인덱스+값
    print("\(index)번째: \(score)")
}

for i in 0..<scores.count {    // 범위 순회
    print(scores[i])
}
```

### 배열 + 고차함수 (다음 챕터에서 자세히)

```swift
let doubled = scores.map { $0 * 2 }          // [190, 160, ...]
let filtered = scores.filter { $0 >= 70 }     // [95, 80, 70]
let total = scores.reduce(0, +)               // 305
```

## 2. 집합 (Set)

중복을 허용하지 않는, 순서가 없는 컬렉션입니다.

```swift
var setA: Set<Int> = [1, 2, 3, 4]
var setB: Set<Int> = [3, 4, 5, 6]

setA.insert(10)          // 추가
setA.remove(1)           // 제거

print(setA.intersection(setB))    // 교집합: {3, 4}
print(setA.union(setB))           // 합집합
print(setA.subtracting(setB))     // 차집합
print(setA.symmetricDifference(setB))  // 대칭 차집합
```

> Set은 중복 제거가 필요하거나, 해당 원소가 존재하는지 빠르게 검사할 때 유용합니다.

## 3. 딕셔너리 (Dictionary)

키(Key)와 값(Value) 쌍으로 데이터를 저장합니다.

```swift
// 1) 리터럴 생성
var capitals: [String: String] = [
    "Korea": "Seoul",
    "Japan": "Tokyo",
    "USA": "Washington"
]

// 2) 값 추가/변경
capitals["China"] = "Beijing"      // 추가
capitals["Japan"] = "Osaka"        // 변경 (키 존재 시)
capitals.updateValue("Osaka", forKey: "Japan")

// 3) 값 읽기 (키가 없을 수 있음 => 옵셔널)
print(capitals["Korea"]!)        // Seoul (강제 언랩)
print(capitals["France"])        // nil

// 4) 제거
capitals.removeValue(forKey: "USA")   // 또는 capitals["USA"] = nil

// 5) 순회
for (country, city) in capitals {
    print("\(country)의 수도는 \(city)")
}

for key in capitals.keys { print(key) }    // 키만
for value in capitals.values { print(value) } // 값만

print(capitals.count)    // 저장된 쌍의 개수
```

> ⚠️ 딕셔너리에서 값을 읽으면 항상 "옵셔널"로 반환됩니다. 키가 없으면 `nil`이기 때문입니다.
> 옵셔널 강제 언랩(`!`)보다는 `if let`, `guard let`을 권장합니다 (뒤 챕터에서 다룸).

## 4. 튜플 (Tuple)

서로 다른 타입의 값들을 묶는 가벼운 구조입니다. 여러 값을 하나로 반환할 때 유용합니다.

```swift
let person = ("Minho", 27, 175.5)

print(person.0)    // "Minho" (인덱스로 접근)
print(person.1)    // 27

// 요소 이름 지정
let user = (name: "Minho", age: 27)
print(user.name)   // "Minho"
print(user.age)    // 27

// 분해 (destructuring)
let (name, age) = user
print(name, age)

// 함수에서 여러 값 반환
func minMax(numbers: [Int]) -> (min: Int, max: Int) {
    let min = numbers.min() ?? 0
    let max = numbers.max() ?? 0
    return (min, max)
}
let result = minMax(numbers: [3, 9, 1, 7])
print("최소: \(result.min), 최대: \(result.max)")
```

```swift
// 범위 (Range) - 반복문과 인덱스에 자주 사용

let halfOpenRange = 1..<5     // 1,2,3,4

```

## 🛠 실습 3: 로또 번호 생성기 (Set 활용)

1부터 45까지 중 6개를 중복 없이 뽑는 프로그램을 만들고, 정렬해서 출력하세요.

```swift
import Foundation

var lottoSet: Set<Int> = []
while lottoSet.count < 6 {
    let num = Int.random(in: 1...45)   // 난수 생성
    lottoSet.insert(num)
}
let sorted = lottoSet.sorted()          // 정렬
print(sorted)
```

**변형 과제**: 몇 번의 시도 끝에 6개를 채웠는지 횟수를 세어 출력하세요.
