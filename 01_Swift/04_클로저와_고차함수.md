# 1.4 클로저와 고차 함수

> 함수처럼 동작하되 '값'으로 사용되는 클로저와, 컬렉션을 다루는 고차 함수를 학습한다.

---

## 학습 목표

- 클로저의 문법과 축약을 이해한다.
- `map`, `filter`, `reduce`, `sorted`, `compactMap`의 동작을 이해한다.
- 함수를 매개변수로 전달하고 반환할 수 있다.

---

## 1. 클로저란?

클로저는 **이름 없이 동작하는 함수**이자 **값으로 전달/저장 가능한 코드 블록**입니다.

```swift
// 1) 함수 형태
func add(a: Int, b: Int) -> Int { return a + b }

// 2) 클로저 형태
let addClosure = { (a: Int, b: Int) -> Int in
    return a + b
}

print(addClosure(3, 4))   // 7
```

### 클로저 문법 해부

```swift
{ (매개변수) -> 반환타입 in
    실행할 코드
}
```

- `in` 앞: 선언부, `in` 뒤: 본문
- 클로저는 `let` 상수에 저장하거나 함수 매개변수로 바로 넘길 수 있습니다.

```swift
let greeting = { (name: String) -> String in
    return "Hello, \(name)"
}
print(greeting("Swift"))   // "Hello, Swift"
```

## 2. 클로저 축약 (유용한 문법)

기본형 → 축약형으로 점점 줄여나가는 과정을 봅시다.

```swift
let numbers = [3, 1, 4, 1, 5]

// [1] 정식 클로저
let r1 = numbers.sorted(by: { (a: Int, b: Int) -> Bool in
    return a < b
})

// [2] 타입 추론(생략)
let r2 = numbers.sorted(by: { a, b in
    return a < b
})

// [3] return 생략 (단일 표현식)
let r3 = numbers.sorted(by: { a, b in a < b })

// [4] 축약 인자 $0, $1
let r4 = numbers.sorted(by: { $0 < $1 })

// [5] 연산자 직접 전달
let r5 = numbers.sorted(by: <)

print(r5)   // [1, 1, 3, 4, 5]
```

### 트레일링 클로저 (Trailing Closure)

클로저가 마지막 매개변수일 때 `(by: ...)`를 생략하고 뒤에 붙일 수 있습니다.

```swift
let r6 = numbers.sorted { $0 < $1 }
```

## 3. 대표 고차 함수

### map: 모든 요소 변환

```swift
let prices = [1000, 2000, 3000]
let taxed = prices.map { price in
    price * 110 / 100
}
print(taxed)   // [1100, 2200, 3300]

let names = ["minho", "suji"]
print(names.map { $0.uppercased() })   // ["MINHO", "SUJI"]
```

### filter: 조건에 맞는 요소만

```swift
let ages = [5, 12, 16, 20, 30]
let adults = ages.filter { $0 >= 19 }
print(adults)   // [20, 30]
```

### reduce: 모든 요소를 하나로 축약

```swift
let numbers2 = [1, 2, 3, 4, 5]
let total = numbers2.reduce(0) { $0 + $1 }
print(total)   // 15

// 초깃값 100에서 시작
let withInitial = numbers2.reduce(100, +)   // 115
```

### compactMap: nil 제거 + 언랩

```swift
let inputs = ["10", "abc", "30", ""]
let ints = inputs.compactMap { Int($0) }
print(ints)   // [10, 30]  (변환 실패한 것은 자동 제외)
```

### flatMap: 중첩 배열 평탄화

```swift
let grid = [[1, 2], [3, 4], [5]]
let flattened = grid.flatMap { $0 }
print(flattened)   // [1, 2, 3, 4, 5]
```

### forEach: 반복 실행

```swift
(1...3).forEach { print($0) }   // 1, 2, 3
```

## 4. 함수를 매개변수로 받는 함수 (클로저 캡처)

```swift
func applyTwice(_ operation: (Int) -> Int, to value: Int) -> Int {
    return operation(operation(value))
}

let result = applyTwice({ $0 * 3 }, to: 5)
print(result)   // ((5*3)*3) = 45

// 트레일링으로 쓰면
let result2 = applyTwice({ $0 * 3 }, to: 5)
```

### 값 캡처 (Capture)

클로저는 정의된 시점의 변수를 **캡처**(기억)합니다.

```swift
func makeIncrementer(step: Int) -> () -> Int {
    var total = 0
    return {
        total += step     // 바깥의 total을 캡처해서 계속 기억
        return total
    }
}

let inc = makeIncrementer(step: 2)
print(inc())   // 2
print(inc())   // 4
print(inc())   // 6
```

## 5. 클로저 실전 패턴: 설정/완료 처리

```swift
// 설정 클로저 (자주 쓰는 패턴: 객체를 만들고 초기 설정만 클로저로)
func configure(_ closure: (inout [String]) -> Void) -> [String] {
    var items: [String] = []
    closure(&items)
    return items
}

let list = configure { items in
    items.append("첫 번째")
    items.append("두 번째")
}
print(list)   // ["첫 번째", "두 번째"]
```

> iOS 개발에서 버튼 액션이나 네트워크 완료 콜백도 전부 클로저의 응용입니다.

## 🛠 실습 3: 로그 데이터 정제 (compactMap)

문자열 배열 로그에서 숫자만 골라내는 프로그램입니다.

```swift
let logs = [
    "user:minho status:200",
    "user:suji status:404",
    "user:jun status:200",
    "error parsing token",
    "user:yeri status:500"
]

// status 뒤의 숫자만 골라 순서대로 출력하세요
// -> [200, 404, 200, 500]
```

**실습 힌트**

- `component(separatedBy: ":")` 또는 정규식/문자열 검색을 활용합니다.
- 간단한 방법: `$0.components(separatedBy: " ").last` 가 "status:200" 형태 → ": "로 split 후 마지막 부분만 Int로.
- `compactMap { Int(...) }` 를 쓰면 실패한 줄은 자동으로 빠집니다.

let scores = [85, 92, 68, 77, 95]

</details>

<details>
<summary>실습 3 정답</summary>

```swift
let logs = [
    "user:minho status:200",
    "user:suji status:404",
    "user:jun status:200",
    "error parsing token",
    "user:yeri status:500"
]

let statuses = logs.compactMap { log -> Int? in
    guard let statusPart = log.components(separatedBy: " ").last,
          statusPart.hasPrefix("status:") else { return nil }
    let code = statusPart.replacingOccurrences(of: "status:", with: "")
    return Int(code)
}

print(statuses)   // [200, 404, 200, 500]
```
</details>
