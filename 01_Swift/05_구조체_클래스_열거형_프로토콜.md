## 1. 구조체 (Struct)

데이터를 값으로 묶는 타입입니다. **복사하면 각자 독립적인 값**을 가집니다.

```swift
struct Person {
    var name: String
    var age: Int

    // 메서드
    func introduce() -> String {
        return "\(name), \(age)살"
    }
}

// 멤버와이즈 이니셜라이저 자동 생성!
let minho = Person(name: "Minho", age: 27)
print(minho.introduce())   // "Minho, 27살"

// 값 타입: 복사는 독립
var copy = minho
copy.name = "Suji"
print(minho.name)   // "Minho" (원본 변화 없음)
```

### 구조체 + 메서드에서 값 변경 시 주의

`mutating` 키워드가 없으면 메서드에서 저장 프로퍼티를 바꿀 수 없습니다.

```swift
struct Counter {
    var value = 0

    mutating func increment() {   // mutating 필요!
        value += 1
    }
}

var counter = Counter()
counter.increment()
print(counter.value)   // 1
```

## 2. 클래스 (Class)

**참조 타입**입니다. 같은 인스턴스를 여러 변수가 가리키면 서로 영향을 줍니다.

```swift
class Animal {
    var name: String

    init(name: String) {          // 이니셜라이저 반드시 정의
        self.name = name
    }

    func speak() {
        print("\(name)의 소리")
    }
}

let a = Animal(name: "냥이")
let b = a            // 같은 객체를 가리킴 (참조 공유)
b.name = "멍이"

print(a.name)        // "멍이"  ← 참조 타입이라 바뀜!
```

### 상속

```swift
class Dog: Animal {
    var breed: String

    init(name: String, breed: String) {
        self.breed = breed
        super.init(name: name)    // 부모 초기화
    }

    override func speak() {       // 메서드 오버라이드
        print("\(breed) \(name): 멍멍!")
    }
}

let puppy = Dog(name: "초코", breed: "말티즈")
puppy.speak()   // "말티즈 초코: 멍멍!"
```

### 구조체 vs 클래스 정리

| 구분 | Struct | Class |
|------|--------|-------|
| 타입 | 값 타입 | 참조 타입 |
| 복사 | 복사본 생성(독립) | 같은 객체 공유 |
| 상속 | 불가 | 가능 |
| 기본 이니셜라이저 | 자동 생성 | 직접 작성 |
| mutating | 저장 프로퍼티 수정 시 필요 | 불필요 |
| 메모리 | 스택/값 지역 | 힙/참조 (ARC 관리) |

> Apple 가이드라인: **되도록 struct를 기본으로**, 상속이 필요하거나 공유 상태가 필요할 때만 class를 사용하세요.

## 3. 열거형 (Enum)

관련 있는 값의 묶음 + 연관 정보를 표현합니다.

```swift
enum Direction {
    case north, south, east, west
}

var dir = Direction.north
dir = .south     // 타입이 정해지면 점으로 축약 가능
```

### 원시값 (Raw Value)

```swift
enum StatusCode: Int {
    case ok = 200
    case notFound = 404
    case serverError = 500
}

print(StatusCode.ok.rawValue)         // 200
print(StatusCode(rawValue: 500))      // serverError (옵셔널)
```

### 연관값 (Associated Value)

케이스별로 추가 정보를 담을 수 있습니다.

```swift
enum Result {
    case success(score: Int)
    case failure(message: String)
}

let result1 = Result.success(score: 95)
let result2 = Result.failure(message: "네트워크 오류")

switch result1 {
case .success(let score):
    print("성공! 스코어 \(score)")
case .failure(let message):
    print("실패: \(message)")
}
```

### enum + switch (자연스러운 조합)

```swift
enum Direction2 {
    case north, south, east, west
}

func description(of d: Direction2) -> String {
    switch d {
    case .north: return "북쪽"
    case .south: return "남쪽"
    case .east:  return "동쪽"
    case .west:  return "서쪽"
    }
}

print(description(of: .north))   // "북쪽"
```

### 계산 프로퍼티를 가진 enum

```swift
enum Weather {
    case sunny, rainy, cloudy

    var advice: String {
        switch self {
        case .sunny:  return "선글라스 착용"
        case .rainy:  return "우산 필요"
        case .cloudy: return "무난한 날씨"
        }
    }
}

print(Weather.rainy.advice)   // "우산 필요"
```

## 4. 프로토콜 (Protocol)

'행동의 청사진'입니다. 어떤 타입이 반드시 가져야 할 속성/메서드를 정의합니다.

```swift
protocol Describable {
    var description: String { get }
    func makeSound()
}
```

### 프로토콜 채택 (Conform)

```swift
struct Robot: Describable {
    var description: String { "로봇" }
    func makeSound() {
        print("삐빅")
    }
}

struct Cat: Describable {
    var description: String { "고양이" }
    func makeSound() {
        print("야옹")
    }
}
```

### 프로토콜을 타입으로 사용 (다형성)

```swift
func announce(_ thing: Describable) {
    print("\(thing.description)입니다.")
    thing.makeSound()
}

announce(Robot())
announce(Cat())
```

> 이 패턴을 **프로토콜 지향 프로그래밍**이라 하며, SwiftUI에서 `View`, `Identifiable`, `Codable` 등이 모두 프로토콜입니다.

## 5. 확장 (Extension)

기존 타입에 새 기능을 추가합니다.

```swift
extension Int {
    func squared() -> Int {
        return self * self
    }

    var isEven: Bool {
        return self % 2 == 0
    }
}

print(5.squared())   // 25
print(4.isEven)      // true
```

### 프로토콜 + 확장 = 기본 구현

```swift
protocol Greeting {
    func greeting() -> String
}

extension Greeting {
    // 기본 구현: 채택한 타입이 안 만들어도 기본 제공
    func greeting() -> String { return "Hello" }
}

struct Korean: Greeting {
    func greeting() -> String { return "안녕하세요" }
}

struct DefaultUser: Greeting {}   // 기본 구현 사용

print(Korean().greeting())        // "안녕하세요"
print(DefaultUser().greeting())   // "Hello"
```

protocol Shape {
    var area: Double { get }
}

struct Circle: Shape {
    let radius: Double
    var area: Double { .pi * radius * radius }
}

struct Rectangle: Shape {
    let width: Double
    let height: Double
    var area: Double { width * height }
}

struct Triangle: Shape {
    let base: Double
    let height: Double
    var area: Double { base * height / 2 }
}

let shapes: [Shape] = [
    Circle(radius: 3),
    Rectangle(width: 4, height: 5),
    Triangle(base: 6, height: 7)
]

let total = shapes.reduce(0) { $0 + $1.area }
print(String(format: "전체 면적: %.2f", total))

        let name: String

}

process(order: .coffee(type: .latte, shots: 2, hasMilk: true))
