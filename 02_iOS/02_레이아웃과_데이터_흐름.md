# 2.2 레이아웃과 데이터 흐름

> SwiftUI의 배치 시스템(VStack/HStack/ZStack/프레임)과 상태 관리의 핵심(@State, @Binding, @Observable)을 학습한다.

---

## 학습 목표

- 스택 레이아웃과 Spacer, frame, alignment를 이해한다.
- `@State`로 뷰 상태를 만들고 `$` 바인딩으로 전달한다.
- `@Binding`으로 뷰 간 상태를 공유한다.
- `@Observable`과 `@Environment`로 여러 화면이 공유하는 데이터를 관리한다.

---

## 1. 레이아웃 시스템

SwiftUI는 **3종류 스택** + **frame/alignment** 로 레이아웃을 구성합니다.

### VStack / HStack / ZStack

```swift
// 세로 배치
VStack {
    Text("위")
    Text("아래")
}

// 가로 배치
HStack {
    Text("왼쪽")
    Text("오른쪽")
}

// 겹치기 (Z축)
ZStack(alignment: .bottomTrailing) {
    Color.yellow
    Text("앵커")
}
```

### alignment & spacing 조절

```swift
VStack(alignment: .leading, spacing: 12) {
    Text("왼쪽 정렬 1")
    Text("왼쪽 정렬 2")
}

HStack(alignment: .top) {
    Text("위쪽 정렬")
    Text("긴 내용은 아래로 늘어남")
}
```

### Spacer와 frame

```swift
HStack {
    Text("왼쪽")
    Spacer()                          // 밀어냄
    Text("거리")
    Spacer(minLength: 50)             // 최소 간격 50
    Text("오른쪽")
}
```

```swift
Text("사각형 영역")
    .frame(width: 120, height: 80)           // 고정 크기
    .frame(maxWidth: .infinity, alignment: .center)  // 확장
    .background(Color.indigo.opacity(0.2))
    .clipShape(RoundedRectangle(cornerRadius: 16))
```

### 정렬 & 가중치 (layoutPriority, frame maxHeight)

```swift
VStack {
    Color.red
        .frame(maxHeight: .infinity)   // 유연한 높이
    Color.blue
        .frame(height: 80)             // 고정 높이
}
```

## 2. 상태 관리 기초: @State

`@State`는 **뷰 내부의 변경 가능한 상태**입니다. 값이 바뀌면 뷰가 자동으로 다시 그려집니다.

```swift
struct CounterView: View {
    @State private var count = 0      // 상태 선언

    var body: some View {
        VStack(spacing: 20) {
            Text("\(count)")
                .font(.system(size: 60))
            HStack(spacing: 20) {
                Button("감소") { if count > 0 { count -= 1 } }
                Button("증가") { count += 1 }
            }
            .buttonStyle(.borderedProminent)
        }
    }
}
```

> **중요**: `@State`는 체크 표시처럼 단순한 <큰 데이터>는 피하고, 값 하나나 간단한 구조체에 사용합니다.
> 화면이 사라지면 상태도 사라집니다 (영속 저장은 2.5 챕터에서).

---

## 3. @Binding: 상태 공유

부모 뷰의 `@State`를 자식 뷰에서 읽고 쓰게 하고 싶을 때 `@Binding`을 사용합니다.

```swift
struct ToggleRow: View {
    @Binding var isOn: Bool       // 부모가 소유한 상태를 연결

    var body: some View {
        Toggle("알림 받기", isOn: $isOn)   // $로 바인딩 전달
            .padding()
    }
}

struct SettingsView: View {
    @State private var notificationOn = false

    var body: some View {
        VStack {
            ToggleRow(isOn: $notificationOn)   // $로 전달
            Text(notificationOn ? "알림 켜짐" : "알림 꺼짐")
        }
    }
}
```

**핵심 규칙**:
- 상태를 **소유하는 곳은 `@State`**
- 상태를 **전달받아 쓰는 곳은 `@Binding`**
- 전달할 때는 `$상태명` 형식

## 4. @Observable: 앱 전체 공유 데이터

여러 화면이 공유하는 모델(예: 사용자, 설정, 장바구니)은 `@Observable` 클래스로 만듭니다.

macOS 14(iOS 17) 이상:

```swift
import SwiftUI
import Observation

@Observable
class UserModel {
    var name = "Minho"
    var coin = 100
}
```

뷰에서 사용:

```swift
struct ProfileView: View {
    @Bindable var user: UserModel     // 상위에서 생성

    var body: some View {
        VStack {
            Text("\(user.name): \(user.coin)코인")
            TextField("이름", text: $user.name)   // $ 가능
                .textFieldStyle(.roundedBorder)
            Button("+10 코인") { user.coin += 10 }
        }
        .padding()
    }
}

struct RootView: View {
    @State private var user = UserModel()   // 소유

    var body: some View {
        ProfileView(user: user)
    }
}
```

### @Environment를 통한 주입

앱 전역에 하나의 모델을 공유하는 가장 깔끔한 방법입니다.

```swift
struct MyApp: App {
    @State private var user = UserModel()

    var body: some Scene {
        WindowGroup {
            RootView()
                .environment(user)    // 전역에 주입
        }
    }
}
```

```swift
struct CoinBadge: View {
    @Environment(UserModel.self) private var user   // 회수

    var body: some View {
        Text("💰 \(user.coin)")
    }
}
```

## 5. 예제: 프로필 편집 화면 통합

`ios-state-demo` 프로젝트를 만들고 아래 내용을 직접 입력해 보세요.

```swift
import SwiftUI
import Observation

@Observable
class User {
    var nickname = "SwiftLearner"
    var bio = "iOS 개발 입문"
    var isPremium = false
}

struct EditProfileView: View {
    @Bindable var user: User

    var body: some View {
        Form {
            TextField("닉네임", text: $user.nickname)
            TextField("소개", text: $user.bio, axis: .vertical)
                .lineLimit(3...5)
            Toggle("프리미엄", isOn: $user.isPremium)
        }
        .navigationTitle("프로필 편집")
    }
}

struct ProfileMainView: View {
    @State private var user = User()

    var body: some View {
        NavigationStack {
            VStack {
                Image(systemName: user.isPremium ? "crown.fill" : "person.fill")
                    .font(.system(size: 80))
                    .foregroundStyle(user.isPremium ? .yellow : .gray)
                Text(user.nickname).font(.title)
                Text(user.bio).foregroundStyle(.secondary)
            }
            .padding()
            .toolbar {
                NavigationLink { EditProfileView(user: user) } label: {
                    Text("편집")
                }
            }
        }
    }
}

#Preview {
    ProfileMainView()
}
```

- `Form` = 설정창 같은 폼 레이아웃
- `NavigationStack` + `NavigationLink`는 다음 챕터에서 상세 학습

## 🛠 실습 1: 할 일 입력기 (TextField + @State/@Binding)

**요구사항** : 새 프로젝트 `TodoInputApp`

1. `TodoInputView` (Binding만 갖는 자식 뷰):
   - `@Binding var text: String`, `onAdd: () -> Void`
   - TextField + "추가" 버튼(눌리면 `onAdd()` 호출 + text 초기화)
2. 부모 뷰:
   - `@State private var todos: [String]`
   - `List`로 할 일 표시
   - `TodoInputView(text: $newTodo, onAdd: { ... })`

## 🛠 실습 2: 테마 토글 (전역 상태)

**요구사항** : `ThemeDemo`

1. `@Observable class Appearance { var isDark = false }`
2. `.environment(appearance)`로 앱 전역 주입
3. 첫 화면: `@Environment(Appearance.self)`로 테마 상태 읽어 `.preferredColorScheme` 적용 + 토글 버튼
4. 두 번째 화면에서도 동일 토글 작동

struct TodoInputView: View {

        .padding()
    }
}
