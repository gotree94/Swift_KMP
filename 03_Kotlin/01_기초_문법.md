> Kotlin 언어의 뼈대인 변수, 함수, 컬렉션, 조건/반복을 Swift와 비교하며 학습한다.

## 1. 실행 환경 준비

Kotlin을 CLI로 실행합니다.

```bash
kotlinc hello.kt -include-runtime -d hello.jar
java -jar hello.jar
```

> Android Studio에서는 Gradle 프로젝트로 실행하지만, 문법 학습은 CLI가 빠릅니다.
> `kotlinc`가 없다면 `brew install kotlin` 또는 Android Studio에 포함된 Kotlin 컴파일러 사용.

`hello.kt`:

```kotlin
fun main() {
    println("Hello, Kotlin!")
}
```

실행: 위 명령어 두 줄 실행 → `Hello, Kotlin!`

## 2. 변수와 상수

```kotlin
var name = "Minho"   // 변경 가능 (Swift의 var)
name = "Suji"        // ✅

val birthYear = 1995 // 변경 불가 (Swift의 let)
// birthYear = 1996  // ❌ 에러

println(name)
println(birthYear)
```

| Swift | Kotlin |
|-------|--------|
| `let` | `val` |
| `var` | `var` |
| `let x: Int = 5` | `val x: Int = 5` |

타입 명시와 추론:

```kotlin
val age: Int = 27
val temperature: Double = 36.5
val isStudent: Boolean = true
val word = "Kotlin"          // 타입 추론

println("이름: $name, 나이: $age")       // 문자열 템플릿 $
println("2+3 = ${2 + 3}")               // 중괄호 연산
```

> 문자열 보간: Swift는 `\(변수)`, Kotlin은 `$변수` 또는 `${수식}`

## 3. 기본 자료형

```kotlin
val a: Int = 10
val b: Long = 10_000_000L
val c: Float = 3.14f
val d: Double = 3.14
val e: Boolean = true
val f: Char = 'A'
val g: String = "문자열"

// 타입 변환 (명시적)
val intVal = a.toDouble()   // 10.0
val str = a.toString()      // "10"
val fromStr = "42".toInt()  // 42 (실패 시 NumberFormatException)
```

`null` 관련: Kotlin은 null 처리가 언어적 강점입니다.

```kotlin
var nickname: String? = null   // ? = nullable
nickname = "민호"

// 안전 호출
val length = nickname?.length   // null이면 null (Swift if let 유사)

// 엘비스 연산자 (Swift ?? 와 동일)
val safe = nickname ?: "게스트"

// 강제 호출 (Swift ! 와 동일, 비추천)
// val forced = nickname!!.length
```

| Swift | Kotlin |
|-------|--------|
| `var x: String?` | `var x: String?` |
| `x?.count` | `x?.length` |
| `x ?? "기본"` | `x ?: "기본"` |
| `x!` | `x!!` |
| `if let x = x` | `val v = x ?: return` 또는 `if (x != null)` |

## 4. 조건문

### if 표현식

Kotlin의 if는 **값을 리턴하는 표현식**입니다.

```kotlin
val score = 85

val grade = if (score >= 90) {
    "A"
} else if (score >= 80) {
    "B"
} else {
    "C"
}
println(grade)   // "B"

// when (Swift의 switch)
val day = 3
val name = when (day) {
    1 -> "월"
    2 -> "화"
    3 -> "수"
    in 4..7 -> "기타 평일"    // 범위 매칭
    else -> "알 수 없음"
}
println(name)   // "수"
```

### when 심화

```swift
fun describe(obj: Any): String = when (obj) {
    is String -> "문자열, 길이 ${obj.length}"
    is Int -> "정수"
    else -> "기타"
}
```

## 5. 반복문

```kotlin
// 범위
for (i in 1..5) {          // 1,2,3,4,5
    print(i)
}
println()

for (i in 1 until 5) {     // 1,2,3,4 (마지막 미포함, Swift ..<)
    print(i)
}
println()

for (i in 10 downTo 1 step 2) {   // 10,8,6,4,2
    print(i)
}
println()

// while
var count = 0
while (count < 3) {
    count++
}
println(count)   // 3
```

## 6. 함수

### 기본 함수

```kotlin
fun greet(name: String): String {
    return "안녕, $name!"
}
println(greet("Minho"))

// 단일 표현식 함수 (간결!)
fun add(a: Int, b: Int) = a + b
println(add(3, 4))   // 7
```

### 기본값 / 명명된 인자

```kotlin
fun order(coffee: String, size: String = "Medium", shots: Int = 1): String =
    "$size $coffee, 샷 $shots"

println(order("Latte"))                    // Medium Latte, 샷 1
println(order("Americano", shots = 3))     // 명명된 인자
```

> Kotlin은 인자 순서를 명명 인자로 자유롭게 바꿀 수 있어 매우 편리합니다. (Swift와 큰 차이)

### 확장 함수 (Swift extension과 유사)

```kotlin
fun String.isPalindrome(): Boolean {
    return this == this.reversed()
}

println("racecar".isPalindrome())   // true
```

### 람다

```kotlin
val square: (Int) -> Int = { x -> x * x }
println(square(5))   // 25

val add2 = { a: Int, b: Int -> a + b }
println(add2(1, 2))  // 3

// 고차 함수
fun applyTwice(op: (Int) -> Int, value: Int): Int = op(op(value))
println(applyTwice({ it * 3 }, 5))   // it: 단일 파라미터 축약, (5*3)*3=45
```

## 7. 컬렉션

### List / Set / Map

```kotlin
// 불변 리스트 (val이 아니라 readOnly 이므로 재할당 불가)
val fruits = listOf("사과", "바나나", "오렌지")
println(fruits[0])               // "사과"
println(fruits.size)
println(fruits.contains("사과")) // true

// 가변 리스트
val mutableFruits = mutableListOf("사과")
mutableFruits.add("포도")
mutableFruits += "키위"
mutableFruits.removeAt(0)

// Set
val unique = setOf(1, 2, 2, 3)          // 중복 제거, {1,2,3}

// Map
val capitals = mapOf("Korea" to "Seoul", "Japan" to "Tokyo")
println(capitals["Korea"])              // "Seoul" (없으면 null)
val mutableCapitals = mutableMapOf("Korea" to "Seoul")
mutableCapitals["China"] = "Beijing"
```

> 주의: Kotlin은 읽기전용(`listOf`)과 가변(`mutableListOf`)을 구분합니다. Swift는 `let`/`var`로 구분했습니다.

### 컬렉션 고차 함수

```kotlin
val numbers = listOf(1, 2, 3, 4, 5, 6)

val doubled = numbers.map { it * 2 }        // [2,4,6,8,10,12]
val evens = numbers.filter { it % 2 == 0 }  // [2,4,6]
val total = numbers.sum()                   // 21
val reduced = numbers.reduce { acc, i -> acc + i }  // 21
val grouped = numbers.groupBy { it % 2 }    // {1=[1,3,5], 0=[2,4,6]}
val avg = numbers.average()                 // 3.5
```

## 8. data class (Swift struct의 멤버와 같은 역할)

```kotlin
data class Person(
    val name: String,
    val age: Int
)

val person = Person("Minho", 27)

println(person.name)          // "Minho"
println(person)               // Person(name=Minho, age=27) - 자동 toString
val copy = person.copy(age = 28)   // 복사본
println(person == copy)       // false
```

> `data class`는 equals/hashCode/toString/copy/componentN을 자동 생성합니다.
> 이 점이 KMP에서 Swift의 struct 모델 대신 쓰이는 핵심 타입입니다.

## 🛠 실습 1: 간단한 계산기 (섭씨↔화씨 변환)

`temperature.kt`를 만들어 보세요.

**요구사항**

1. `fun celsiusToFahrenheit(c: Double): Double = c * 9 / 5 + 32`
2. `fun fahrenheitToCelsius(f: Double): Double = (f - 32) * 5 / 9`
3. main에서 0°C, 100°C, 32°F, 212°F 변환 결과 출력
4. `readLine()?.toDoubleOrNull()` 로 사용자 입력도 받아 볼 것

**실습 힌트**

```kotlin
fun main() {
    println("온도 입력:")
    val input = readLine()?.toDoubleOrNull()
    if (input != null) {
        println("화씨: ${celsiusToFahrenheit(input)}")
    } else {
        println("잘못된 입력")
    }
}
```

## 🛠 실습 2: 단어 빈도 분석기 (컬렉션 고차함수)

**요구사항**

문자열 문장을 단어로 쪼개 각 단어의 빈도를 세는 프로그램.

```kotlin
val text = "kotlin is fun and kotlin is powerful"
// 1) split(" ") 로 리스트화
// 2) groupingBy 사용해 빈도 계산
// 3) 빈도 순 정렬 출력
```

**실습 힌트**

```kotlin
val freq = text.split(" ").groupingBy { it }.eachCount()
println(freq)   // {kotlin=2, is=2, fun=1, and=1, powerful=1}
```

## 🛠 실습 3: 마스크 재고 확인기 (data class + when)

**요구사항**

## 실습 풀이

<details>
<summary>실습 2 정답</summary>

```kotlin
fun main() {
    val text = "kotlin is fun and kotlin is powerful"
    val freq = text.split(" ")
        .groupingBy { it }
        .eachCount()
        .toList()
        .sortedByDescending { it.second }

    for ((word, count) in freq) {
        println("$word: $count회")
    }
}
```
</details>

<details>
<summary>실습 3 정답</summary>

```kotlin
data class MaskStore(val name: String, val stock: Int)

fun status(stock: Int): String = when {
    stock <= 0 -> "품절"
    stock <= 10 -> "임박"
    else -> "여유"
}

fun main() {
    val stores = listOf(
        MaskStore("편의점A", 0),
        MaskStore("약국B", 5),
        MaskStore("마트C", 40)
    )

    stores.sortedByDescending { it.stock }.forEach { store ->
        println("${store.name}: ${store.stock}개 (${status(store.stock)})")
    }
}
```
