## 1. 클래스

```kotlin
class Animal(val name: String) {      // 생성자 + 프로퍼티 한 번에
    fun speak() {
        println("$name 의 소리")
    }
}

fun main() {
    val a = Animal("냥이")
    a.speak()   // "냥이 의 소리"
}
```

- `val name: String`은 생성자 인자 = 자동 프로퍼티
- `var`면 변경 가능 프로퍼티

### 기본값 / 보조 생성자

```kotlin
class Person(
    val name: String,
    val age: Int = 0   // 기본값
)

class House {
    var address: String

    init {              // 초기화 블록
        address = "서울"
        println("House 생성됨")
    }
}
```

### getter/setter 커스텀

```kotlin
class Circle(private val radius: Double) {
    val area: Double
        get() = radius * radius * Math.PI   // 계산 프로퍼티
}

println(Circle(3.0).area)   // 28.27...
```

## 2. 상속과 추상 클래스

```kotlin
open class Vehicle(val name: String) {   // open = 상속 허용
    open fun move() {
        println("$name 이동")
    }
}

class Car(name: String) : Vehicle(name) {
    override fun move() {
        println("$name 도로로 달립니다")
    }
}

// 추상 클래스
abstract class Payment {
    abstract fun pay(amount: Int): Boolean

    fun log() { println("결제 로그 기록") }
}

class CardPayment : Payment() {
    override fun pay(amount: Int): Boolean {
        println("카드로 ${amount}원 결제")
        return true
    }
}
```

> Swift의 `final`, `override`와 유사하지만, Kotlin은 상속을 막기 위해 `final`(기본)이 아니라 명시적 `open`을 요구합니다. 기본이 final입니다.

## 3. 인터페이스

```kotlin
interface Describable {
    val description: String
    fun describe(): String = description   // 기본 구현 가능
}

class Robot : Describable {
    override val description = "로봇"
}

class Cat : Describable {
    override val description = "고양이"
    override fun describe(): String = "$description: 야옹"
}

fun main() {
    val things: List<Describable> = listOf(Robot(), Cat())
    things.forEach { println(it.describe()) }
}
```

## 4. object와 companion object

### object (싱글턴)

```swift
object AppConfig {
    val apiUrl = "https://api.example.com"
    const val VERSION = "1.0.0"

    fun printInfo() = println("$apiUrl v$VERSION")
}

fun main() {
    AppConfig.printInfo()   // 객체를 만들 필요 없음, 전역 1개
}
```

### companion object (클래스에 붙은 정적 멤버)

```kotlin
class User private constructor(val name: String) {
    companion object {
        fun create(name: String): User {
            println("User 생성: $name")
            return User(name)
        }
    }
}

fun main() {
    val u = User.create("Minho")   // companion 호출
}
```

## 5. sealed class

상속 계층이 제한된 클래스로, `when`과 조합하면 **모든 경우를 언어가 강제**합니다.
KMP에서 상태/UI 이벤트 모델링에 매우 널리 쓰입니다.

```kotlin
sealed class UiState {
    data class Loading(val message: String) : UiState()
    data class Success(val data: String) : UiState()
    data class Error(val message: String) : UiState()
    object Empty : UiState()
}

fun render(state: UiState) {
    when (state) {                    // else 없이 모든 경우 강제
        is UiState.Loading -> println("로딩: ${state.message}")
        is UiState.Success -> println("성공: ${state.data}")
        is UiState.Error -> println("오류: ${state.message}")
        UiState.Empty -> println("비어있음")
    }
}
```

> `when` + sealed class는 Swift의 `enum + 연관값`과 비슷한 강력한 패턴입니다.

## 6. scope 함수

객체를 편하게 다룰 때 사용하는 5가지 표준 함수입니다.

```kotlin
data class Todo(var title: String, var done: Boolean = false)

fun main() {
    // apply: 객체를 반환 (구성/설정)
    val todo = Todo("").apply {
        title = "KMP 공부"
        done = false
    }
    println(todo)

    // run: 결과를 반환
    val isDone = todo.run {
        done = true
        done
    }
    println("완료: $isDone")

    // let: null 안전 처리 + 새 변수로 사용
    val length = todo.title.let { it.length }

    // also: 그대로 두고 부수 효과
    todo.also { println("확인: $it") }

    // with: 주로 리시버 반복 줄이기
    with(todo) {
        println(title)   // "KMP 공부" println(todo.title)과 동일
    }
}
```

요약 표:

| 함수 | 리시버 | 반환값 | 대표 용도 |
|------|--------|--------|-----------|
| `also` | it | 자기자신 | 로깅/사이드효과 |
| `let` | it | 람다 결과 | null 안전 / 변환 |
| `apply` | this | 자기자신 | 프로퍼티 설정 |
| `run` | this | 람다 결과 | 계산/추출 |
| `with` | this | 람다 결과 | 그룹 처리 |

## 7. 함수형 스타일

### filter/map/groupBy 조합

```kotlin
data class Purchase(val item: String, val price: Int)

fun main() {
    val purchases = listOf(
        Purchase("커피", 4500),
        Purchase("샌드위치", 3000),
        Purchase("케이크", 7000),
        Purchase("음료", 2000)
    )

    // 5000 미만 상품의 가격 합
    val cheapTotal = purchases
        .filter { it.price < 5000 }
        .map { it.price }
        .sum()
    println("5000 미만 합계: $cheapTotal원")   // 9500

    // 가격대별로 그룹핑
    val byTier = purchases.groupBy { if (it.price >= 5000) "고가" else "저가" }
    println(byTier.map { "${it.key}: ${it.value.size}건" })

    // take/drop
    val top3 = purchases.sortedByDescending { it.price }.take(3)

    // any/all/none
    println(purchases.any { it.price > 10000 })       // false
    println(purchases.all { it.price > 0 })           // true
}
```

### fold (Swift reduce)

```kotlin
val total = (1..10).fold(0) { acc, i -> acc + i }
println(total)   // 55
```

**요구사항**

1. `class Stack<T>` : push/pop/isEmpty
2. `fun <T> List<T>.midpoint(): T?` 확장 함수 구현 (중간 요소, 짝수면 둘 중 첫)
3. Stack에 Int/String/Object 넣어 동작 확인

```kotlin
class Stack<T> {
    private val items = mutableListOf<T>()

    fun push(item: T) = items.add(item)
    fun pop(): T? = if (items.isEmpty()) null else items.removeAt(items.size - 1)
    val isEmpty: Boolean get() = items.isEmpty()
}
```
