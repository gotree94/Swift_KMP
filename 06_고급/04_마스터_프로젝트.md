# 6.4 마스터 프로젝트: 전체 기술을 결합한 앱

> 지금까지 익힌 Swift/SwiftUI, Kotlin, KMP, SQLDelight, Ktor, Compose Multiplatform, 테스팅, CI/CD를 하나의 완성형 앱으로 통합한다.

---

## 프로젝트 개요

**"TravelMate" — 여행 계획 앱**

- 공용 로직(KMP shared)으로 여행지·일정·예산을 관리
- Android와 iOS에서 동일한 화면(Compose Multiplatform)
- 여행지 정보는 공개 API(DummyJSON 등) 조회
- 오프라인에서도 일정 저장(SQLDelight)
- 테스트 + CI/CD 배포까지 마무리

---

## 목표 (완성 기준)

| 영역 | 요구사항 |

## 4단계: Repository & UseCase

```kotlin
class TripRepository(
    private val remote: TravelRemoteDataSource,
    private val local: TripLocalDataSource
) {
    fun observeTrips(): Flow<List<Trip>> = local.observeTrips()

    suspend fun addTrip(trip: Trip) = local.insertTrip(trip)
    suspend fun togglePlan(tripId: Long, planId: Long) = local.togglePlan(tripId, planId)
    suspend fun deleteTrip(id: Long) = local.deleteTrip(id)
    suspend fun syncDestinations() = remote.fetchHotDestinations()
}
```

## 5단계: UI (Compose Multiplatform 공용)

### 화면 구성

```
TripListScreen  (여행 목록 + 생성 버튼)
  └─ TripDetailScreen (일정 탭 + 예산 카드 + 삭제)
       └─ AddTripScreen (폼: 이름/도시/날짜/예산)
       └─ DayPlanRow (완료 체크/토글)
```

### 상태 패턴

```kotlin
sealed interface TripUiState {
    data object Loading : TripUiState
    data class Success(val trips: List<Trip>) : TripUiState
    data class Error(val message: String) : TripUiState
}

@Composable
fun TripListScreen(viewModel: TripViewModel) {
    val state by viewModel.state.collectAsState()

    when (val s = state) {
        TripUiState.Loading -> CircularProgressIndicator()
        is TripUiState.Error -> ErrorRetry(s.message) { viewModel.load() }
        is TripUiState.Success -> LazyColumn {
            items(s.trips, key = { it.id }) { trip -> TripCard(trip) }
        }
    }
}
```

### 네비게이션

### 예산 카드

```kotlin
@Composable
fun BudgetCard(trip: Trip) {
    val ratio = if (trip.budget > 0) trip.spent.toFloat() / trip.budget else 0f
    Card {
        LinearProgressIndicator(progress = { ratio })
        Text("예산 ${trip.budget}원 / 지출 ${trip.spent}원 / 잔액 ${trip.remainingBudget}원")
    }
}
```

## 마스터 프로젝트 확장 아이디어

기본 TravelMate를 완성했다면 아래 중 선택해 더 고도화합니다:

1. **여행지 검색** — `expect/actual`이 필요 없는 순수 로직 검색(이름/태그 contains)
2. **사진 첨부** — `expect/actual`로 기기에 사진 접근 (iOS Photos, Android MediaStore)
3. **푸시 알림** — KMP에서 플랫폼 푸시 API 브리징
4. **공유/링크** — 딥링크 처리 (플랫폼별 URL 스킴)
5. **위젯** — iOS WidgetKit / Android AppWidgets (네이티브 영역)
6. **캐시 정책** — 오프라인 우선을 더 정교하게 (리바운드 지수 백오프 등)
